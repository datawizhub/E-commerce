# Surface direction contracts

## Storefront · Persuade / browse

THESIS: Everyday clothing is discovered through large, calm photography and a clear path into a real collection.

OWN-WORLD: The owner’s 2 November Nomu reference supersedes the provisional system: Inter typography, cream #FFF9F6, navy #0F151D and coral #FF7448, rounded imagery, pill actions and fine rules. Current evidence and detailed contract: docs/NOMU-RESTYLE.md.

STORY: Explore an edit, narrow by actual garment variants, inspect a piece and its descriptive details. Shared products retain their categories while appearing in promotions.

FIRST VIEWPORT: Compact navy announcement, inset white pill navigation, and a 52/48 photographic hero: oversized two-tone Inter headline at left, rounded blue-coat photograph at right. Coral collection action with navy text. At 950px the hero stacks centred copy over photography; mobile uses 24px panel corners. The subtle image reveal retains reduced-motion support.

FORM: User-pinned Nomu typography and colour reference, applied through code to existing commerce layouts. No generated comp or new identity selection. Keep the Common Form demonstration identity and existing product content.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Admin · Operate

THESIS: A single local workspace keeps catalog edits, inventory, offers, and content understandable.

OWN-WORLD: Shared Inter, cream/navy/coral palette, with a persistent desktop sidebar, clear tables, labelled fields, compact 10–16px field/panel corners, and pale blue status badges.

STORY: Create a product and its descriptive attributes, organise it, adjust stock with a reason, and save offers. Site content has a shared draft/preview/publish cycle.

FIRST VIEWPORT: A 235px pale-cream sidebar with coral current navigation, 70px local-preview bar, and task heading. The overview has a pale coral/photo panel and direct actions; editors retain their working layout. Mobile uses a toggled sidebar and contained table scrolling.

FORM: User-pinned Nomu system adapted to task interfaces; no separate aesthetic selection. Demo storage remains local to the browser; admin remains openly accessible without simulated authentication.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
